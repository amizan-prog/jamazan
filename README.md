# Jam Azan Pintar - WebApp Masjid

Aplikasi Jam Azan web berasaskan PWA (Progressive Web App) dengan ciri penjadualan media (Dashboard) dan latar belakang *slideshow* masjid-masjid di Malaysia (Masjid Putra, Masjid Negara, Masjid Kristal, dll).

## Ciri-ciri
1. **100% Offline (PWA):** Berfungsi tanpa internet selepas dimuatkan (waktu solat dikira secara tempatan menggunakan `adhan.js`).
2. **Slideshow Latar Belakang:** Paparan statik kini digantikan dengan rekaan *Glassmorphism* dan *slideshow* masjid.
3. **Sistem Penjadualan:** Boleh menetapkan media (Gambar, Video tempatan, YouTube Live Makkah) untuk dimainkan pada waktu tertentu atau berhenti *x* minit sebelum Azan dilaungkan.
4. **Selingan Hadis & Quran:** Teks berputar automatik.

## Cara Pemasangan di GitHub Pages
1. Cipta repositori (*repository*) baru di GitHub (contoh: `jam-azan-masjid`).
2. Muat naik semua fail ini (`index.html`, `style.css`, `app.js`, `sw.js`, `manifest.json`) ke dalam repositori tersebut.
3. Pergi ke tab **Settings** > **Pages** di GitHub.
4. Pada bahagian **Source**, pilih branch `main` atau `master`, kemudian klik **Save**.
5. GitHub akan menjana satu pautan unik (URL) percuma. Buka URL tersebut di Smart TV, Android Box, atau PC Masjid anda!
